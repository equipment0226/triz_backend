# 과학효과 1,500개 조사·중복 검토

2026-09-26 정본 **1,500개, 19개 기능군**. 이번 확장에서는 1,200개 기준본에 후보 301개를 작성하고, 교차 검토에서 중복 1개를 대표 항목으로 통합하여 **순증 300개**를 반영했다.

## 계수와 중복 판단

원래 959개에서 9개 통합 후 250개를 추가한 1,200개 완료 기록은 `audit-2026-09-26-before1500/review-2026-09-26.md`에 보존했다. 이번에는 14–27번의 14개 배치로 301개를 작성했다. 전체 이력의 계수는 **959 − 9 + 551 − 1 = 1,500개**다.

신규 후보마다 가까운 기존·동시 추가 항목과의 구분 근거를 배치 TSV와 대응 audit JSON에 남겼다. 최종 추가 교차 대조 36쌍은 `final-cross-review-1500-2026-09-26.tsv`에 기록했다. 자동 문자열 유사도는 검토 대상을 찾는 보조 수단으로만 사용했다. 전체 항목의 모든 쌍에 대한 의미적 비중복을 증명한 것은 아니다.

메틸 표지 보호의 제한·수식 판별은 기존 DNA 메틸화의 인식 변화와 서열 선택 절단의 조건부 결합에 가까워 추가 계수를 철회했다. 원 배치·판정 이력을 지우지 않고, 출처를 기존 `dna-cytosine-covalent-methylation`에 연결했다. 아직 서비스용 ID를 발급하지 않은 후보였으며, 메커니즘 키의 리다이렉트를 보존했다. 상세 판정은 `campaign-merge-decisions-2026-09-26.json`에 있다.

단순 재료·용도 변경, 이름만 다른 반응, 기존 경로의 조합은 제외했다. 전기장 반응 장벽 조절은 기존 슈타르크 효과의 응용 경계에 가까워 별도 계수하지 않았다. 예를 들어 Rabi 진동·기하 위상 변형, 별도 트랜스글루타미나아제, 리보자임 종류별 분할, 다층 몬테카를로·Hutch++ 별도 항목을 추가하지 않았다. 후반 화학 후보에서도 Hock·벤질산 재배열·동적 광학 분할의 경계를 다시 확인해 제외했다.

항목 수는 물리·화학·생물·정보 분야의 대표 작동기전과 조건을 갖춘 세부 경로 수다. **독립 자연법칙 1,500개를 의미하지 않는다.** 포획 기체의 증발 냉각, 뉴클레오솜 DNA 이동, 벤젤 완전 젖음, 백스테핑처럼 넓은 기능 카드와 상하위 관계가 있는 항목은 그 관계와 구체적 경로를 명시했다.

## 출처와 읽은 범위

1,500개 모두 최소 하나의 연결 문헌을 가진다. 신규 근거는 원논문, 저자·기관 공개 원본, 공식 기술 문서를 중심으로 확인했다. `reference_observations.json`은 검색 발췌·초록·본문 구간 등 실제 확인 범위를 구분한다. 전체 논문의 모든 본문을 읽었거나 모든 응용 성능을 실증했다는 뜻은 아니다.

[이온 채널링의 Lindhard 원논문](https://gymarkiv.sdu.dk/MFM/kdvs/mfm%2030-39/mfm-34-14.pdf)에서 연속 퍼텐셜·횡운동·임계각 설명을 확인하고, 큰 핵 충돌 감소를 양전하 이온에 한정했다. [공식 성장의 Galvele 원논문](https://aboutcorrosion.s3.amazonaws.com/Journal%20articles/Galvele/Transport%20processes%20and%20the%20mechanisms%20of%20pitting%20of%20metals.pdf)은 용해·가수분해·수송·국소 산성화 경로의 직접 근거로 사용했다. 이전에 찾은 응용 초록만으로 미시경로까지 확인했다고 표시하지 않았다.

23–27번의 간결한 문헌 검토·제외 후보 기록은 `source-review-batch-*`에 있다. 검색 원응답은 로컬 `.deployment/research1500-web-*`에 보존하고 Git에는 정본·출처 목록·검토 이력·간결한 근거 기록을 반영했다. 양자 확률 역류의 이론 성격, 소수성 기공 탈습윤의 계산 연구 성격, 복합체 I 세부 결합 모형의 불확실성도 카드 조건에 남겼다.

## 특허 검토와 서비스 배포

특허 순차 조사 위치는 **81페이지 완료, 다음 82페이지, 커서 AT-512674-A1**이다. 기존 집계는 수집 13,160건, 초록 검토 10,851건, 초록 없음 2,309건이다. 계정 상태 객체를 특허 페이지로 인정하지 않았으며 커서를 전진시키지 않았다. 이번 301개 후보 조사는 공개 문헌 보강이므로 새 특허 검토 건수에 더하지 않는다. 외부 LLM API 호출은 0회다.

정본과 `pilot/triz/knowledge/effects.json`, `effects_sources.json`을 갱신했다. Git 반영은 `research/effects-1500-20260926` 브랜치에서 진행한다. Railway 배포는 예산 확보 후로 보류하며 이번 작업에서 서비스 배포·예산 변경·재시작을 실행하지 않는다.
