# EUV 실행 ARIZ Part4 중단 수정

2026-09-28 운영 기록에서 DEEP 실행이 S5의 ARIZ Part4 응답 처리 중 중단된 것을 확인했다. 최종 오류는 `ValueError: JSON root container is malformed`였다. 두 응답 모두 공급자 종료 사유는 `stop`이었고 사용량이 정산되어 있었다. 총비용은 $0.194944 / 프로젝트 한도 $2로, 예산이나 출력 길이 한도로 인한 중단은 아니었다.

응답의 `table_columns` 뒤에 표의 행 배열이 바로 이어지면서 `table_rows` 키와 여는 괄호가 누락됐다. 첫 응답의 오류 위치는 문자 4778, 두 번째는 5939였다. 기존 형식 교정 요청이 응답 앞 4000자만 전달해 실제 오류 위치를 포함하지 못했다.

변경 내용:

- 표의 열 바로 다음에 있는 완결된 문자열 행 배열에 한해 누락된 `table_rows` 구조를 복구한다. 행 길이가 열 수와 다르거나, 값/키가 모호하거나, 전체 JSON이 불완전하면 복구하지 않는다. 셀과 분석 문장을 생성하거나 버리지 않는다.
- 형식 교정 재시도에 파서 오류 및 실제 오류 주변을 포함한다. 기존 4000자 범위를 유지한다.
- 사용량이 정산된 실패 응답이 새 파서로 완전히 해석되면 추가 공급자 호출 없이 재사용한다. 원래 FAILED 호출과 과금 기록은 유지하고 `ACTION_FORMAT_RECOVERED` 감사 이벤트를 기록한다. UNKNOWN 과금 상태나 길이 제한 응답은 이 경로로 재사용하지 않는다.
- S5 중간 저장으로 solve/coherence 투영이 바뀌어도 문제·분석·정의 입력이 그대로인 필수 트랙은 원래 읽기 버전을 유지한다. 의미 재계획 또는 실제 입력 변경 시에는 이전 호출을 재사용하지 않는다.
- ARIZ 필수 검토 중단은 일반적인 재시도 문구 대신 실패한 Part와 상세 사유를 표시한다. 필수 ARIZ 검사 자체는 유지한다.

검증:

- 해당 실행의 저장된 두 응답을 로컬에서 복구한 뒤 기존 Part4 필수 단계 검사 통과. 공급자 재호출 없음.
- JSON/기존 순위 응답 복구/ARIZ 필수 단계/실행 수명주기 회귀: 134 passed.
- 추가된 재개 입력 버전 검사 포함 JSON/AX 리팩터/기존 AX 회귀: 73 passed.
- 합성 회귀 사례는 코드에 포함했고, 운영 응답 전문은 Git에 포함하지 않았다.

실제 프로젝트의 재실행 및 후속 LLM 호출은 수행하지 않는다. 운영 배포 후 사용자 화면의 ‘이어서 실행’으로 후속 분석을 진행할 수 있다. 이는 분석 내용의 물리적 타당성 검증 결과가 아니다.
