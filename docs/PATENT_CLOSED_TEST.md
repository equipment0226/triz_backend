# Patent (Test) 비공개 사용자 시험

TRIZ v3.1.2 위에 추가하는 특허 초안 모듈이다. TRIZ 릴리스·전역 모델·프로젝트 예산·원본 state·보고서·특허 원문은 수정하지 않는다. 특허 케이스·원장·작업·비용·첨부는 새 `patent_draft_*` 7개 테이블에 저장한다.

## 접근과 화면

- 기존 로그인 세션에 연결된 서버 계정 이메일이 `equipment0226@gmail.com`인 회원만 이용한다. 사용자명이나 클라이언트 이메일 헤더는 권한 근거가 아니다.
- 다른 계정 및 비로그인은 Patent 페이지에서 `준비 중 입니다.`만 표시한다. 숨긴 화면은 마운트하지 않으며 API 요청도 시작하지 않는다.
- API 읽기·쓰기·다운로드, MCP 호출, 모델 실행 및 CPU 이미지 작업에 서버 측 제한을 적용한다. 기존 공개 사례 권한은 유지한다.
- 필수 적용 변경사항·제약조건·위험 질문, 발명정보와 청구범위 확인, 수정안 비교, 재로그인·새로고침 복원을 제공한다.

## 실행·자료·출력

T1/T2 작성 → 코드 검사 → T3 기술·특허 독립 검토 → 쟁점 보강·역질문·소유자 수정 → 영향받은 검토 재실행 → T3 최종 검토 → 고정된 manifest 확인 후 ZIP 출력이다. 세 T3 역할은 다른 tier로 대체되지 않는다. 타깃·readset·규칙 누락, 출력 잘림, 도구 호출, 응답 모델 불일치는 검토 성공으로 처리하지 않는다.

연결 문헌·상세 원문 캐시를 먼저 사용하고 로컬 ANN/SQL 검색 후 필요한 KR 출원번호만 상세 조회한다. BigQuery 재적재·전체 재색인·모든 문헌 일괄 상세 조회는 없다. KIPRIS 키는 로그에서 숨긴다.

PDF는 별도 프로세스에서 최대 20 MB/30쪽/100,000자/15초로 추출한다. 페이지별 검토 타깃을 만들며 일부만 읽은 문서나 미검토 이미지는 완전 검토로 표시하지 않는다. 첨부 변경은 초안과 검토를 무효화하며, 검토에서 제외해도 원본·과거 버전은 보존한다.

공식 14~17호 서식 PDF 원문·버전·SHA-256을 고정하고, 편집 가능한 DOCX·HTML·Markdown·SVG와 첨부서류 확인 목록을 제공한다. 개념도·생성 이미지는 출원용 도면 후보와 분리한다. 생성 이미지는 사건당 최대 1개이고, 검토 상태와 관계없이 다음 문구를 유지한다.

> 해당 이미지는 생성형 AI를 활용한 샘플 이미지입니다.

공식 작성기의 형식 검증, HWPX/HLZ 제출 파일 생성, 전자서명, 제출·납부, 변리사 컨택은 제공하지 않는다. 출력은 검토용 초안이며 `editor_validation=NOT_RUN`이다. 조건부 증빙의 실제 충족 여부와 출원서 상세 인적사항·공식 형식의 최종 완성은 부분 구현이다.

## 비용·환경·배포

`pilot/patent_draft/config/runtime.env.example`에 모든 특허 환경변수를 명시했다. 기본 플래그는 모두 꺼져 있다. 키와 실제 도메인은 저장소에 넣지 않는다.

- 초기 케이스 비용 한도는 0이다. 회원이 화면에서 자료 전송·보관정책과 총 예산을 승인한 뒤에만 유료 작업을 시작한다. 화면 권장 한도는 필수 검토 예약액과 생성 여유액으로 계산하며 자동 승인되지 않는다.
- 예시 프로필 T1/T2는 동일한 저비용 모델, T3는 추론 모드를 사용한 고급 모델이다. 입력 상한은 잘라내기를 피하기 위한 UTF-8 바이트 기반 보수적 기준이다. 3개 필수 검토와 최대 2회 수정에 대한 9회 최댓값을 먼저 확보한다.
- 예시 가격·한도의 T3 예약액은 US$4.282128이다. 생성 비용은 이 금액 외에서 지출한다. 사건별 사용자 승인 상한은 최대 US$100이며 기존 TRIZ의 US$2 기본값과 별개다.
- CPU 이미지 예약 US$0.20은 청구 확정액이 아니다. Railway 실측 비용과 대조하기 전까지 미확정 비용으로 남긴다.
- 사용량을 모르는 공급자 오류는 예약액을 미확정으로 보존하고 자동 재과금하지 않는다. 전송 전 거절에는 비용이 없고 T3 예약은 복원한다.
- 기존 설정·볼륨·보호 파일의 해시를 기록한 후 신규 테이블만 명시적으로 생성한다: `cd pilot; python -m scripts.patent_draft_migrate` (계획), `python -m scripts.patent_draft_migrate --apply` (적용). 원본 스키마의 컬럼·기본값·NULL성·인덱스 지문을 비교한다.
- 플래그를 켜기 전에 API·브라우저·회귀 시험과 비허용 계정 차단을 확인한다. 롤백은 특허 플래그를 끄고 이전 배포를 복원한다. 신규 데이터는 삭제하지 않는다.

## RL 및 검증 한계

기존 `triz.ax.learning`에는 특허 namespace용 학습 계약이 없어 `TELEMETRY_ONLY`로 명시한다. 실제 governor 의사결정·필수 행동 제한·정책 고정·피드백 성숙도·원본 사건 단위 데이터 분할을 구현했다. 학습 완료 또는 정책 향상으로 표현하지 않는다. 호환 trainer가 생길 때 사용하는 adapter는 운영 초안 작성을 기다리게 하지 않는다. TRIZ Studio 베타 이력은 원본값을 보존한 채 외부 공개위험/감점/부정 라벨 집계에서 제외하며 법적으로 공개가 없었다고 단정하지 않는다.

오프라인 fixture 모델은 시험 전용이며 운영 gateway로 배포하지 않는다. 실모델 의미 정확도, 유료 E2E, KIPRIS 실권한 상세조회, 공식 작성기 검증, 특허 RL 학습은 별도 `NOT_RUN` 항목이다. 93개 규칙 등록·missing 판정 및 핵심 분기 계약시험은 전체 93개의 의미적 POS/NEG 실사례 평가 완료와 같지 않다.

주요 시험 명령:

```text
python -m pytest -q pilot/tests
python -m pytest -q pilot/tests/test_patent_image_jobs.py
npm run build
npm run test:server
npx playwright test
```

실제 로컬 API에 연결하는 `tests/patent-api-integration.spec.js`는 `PATENT_BROWSER_API`가 없으면 명시적으로 건너뛴다. 시험 API 서버는 임시 SQLite와 fixture 공급자를 사용하며 운영 배포물에 포함하지 않는다.
