# 실제 실행 데이터

설계 문서의 흐름이 실제 분석에서 어떻게 이어지는지 보여 주는 사례입니다. DB에 저장된 값과 실행 순서를 기준으로 정리하며, 저장되지 않은 과정은 따로 표시합니다.

| 사례 | 실행 범위 | 포함 내용 |
|---|---|---|
| [로테이션 구동계 + 정렬·클램프 직렬 구간](rotation-serial-latest/README.md) | 2026-09-30 KST, 가장 최근 완료 재실행, epoch 47–52 | 13개 Stage, 실제 하위 처리 92건과 상속 S0, 입출력·검증·사용자 응답·비용 |

각 사례는 **전체 흐름 → Stage → 하위 처리 → 실제 데이터** 순서로 읽을 수 있습니다. 개인정보·인증 정보와 반복되는 프롬프트 전문은 제외하며, 수집 범위와 해석 한계를 사례 안에 함께 적었습니다.
