# TRIZ AX v3.1.1 verification

Release identifier: `triz-ax-v3.1.1`. The serialized workflow identifier remains
`triz-ax-v3.1` for existing project and resume compatibility. New bundles pin the
release, code hashes, prompts, model configuration, effects and policy version.

## Included behavior

- AX reports use the existing full TRIZ template and diagram renderer. Problem
  definition, system analysis, TRIZ methods, evaluation and recorded step trace
  are restored. Markdown, HTML and ZIP use the same frozen report inputs.
- Existing AX snapshots recover recorded analysis without changing the source.
  Historical metadata absent from a snapshot is explicitly identified; no
  invented step history, cost or date is substituted.
- Five is a minimum portfolio target, not a display limit. Every retained
  candidate is returned. Hard failures remain excluded; ambiguous candidates
  retain their missing conditions and validation status.
- Candidate checks bind intervention, target, physical change, intermediate
  functions, operating conditions and tests of both contradiction sides.
  Integrated source ancestry is recognized without accepting unrelated conditions.
- Additional exploration and repair use the existing governed executors with
  bounded attempts and a validation reserve. The coordinator does not request
  human approval. Existing problem confirmation and feedback remain separate.
- Learning supports versioned 8/12-feature policies with the existing trainer.
  Current-run policies remain pinned. Structural gaps do not receive a positive
  technical success label. Synthetic weight updates are tested; improved field
  performance is not claimed.

No legacy schema, serializer, 13-stage order, global model configuration, project
budget configuration or authentication implementation was changed. The default
project budget remains US$2 and existing explicit higher limits remain intact.
Patent prototype files and generated patent images are outside this release.

Failures found and addressed during verification:

- A single-letter CECA label replacement corrupted appendix headings.
- A workflow identifier change broke explicit `triz-ax-v3.1` creation; release
  and serialized workflow versions are now separate.
- Merged source conditions were incorrectly treated as foreign conditions.
- The local frontend install lacked its locked Google authentication dependency.
  `npm ci` restored it; the server test now fails promptly if startup exits.
- The first browser sweep passed 38/41. Three multi-page tests exceeded a shared
  30-second test deadline. All four affected desktop/mobile scenarios passed
  individually with a 60-second deadline; assertions were retained.
