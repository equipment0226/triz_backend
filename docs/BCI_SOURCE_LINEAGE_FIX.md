# S6 통합 원안 제외 의견과 대표안 판정 구분

BCI 전극 분석은 마지막 S6 묶음에서 대표안 하나를 정상 생성했지만, 이미 그 대표안에 통합된 원안 하나를 별도 `excluded` 항목으로 반환했다. 전체 대표안 판정 검증은 이를 미배정 ID로 판단했다. 재개할 때 완료된 호출 응답을 재사용하므로 같은 오류가 반복됐다. 호출 결과·비용이 미확인인 문제가 아니었다.

`normalize_concept_lineage`는 현재 대표안에 유일하게 속하는 원안의 추가 제외 의견만 정규화한다. 대표안 자체의 판정이 정확히 하나 있고 전체 배정 검증을 통과하는 경우에만 원안 의견을 별도 계보 기록으로 이동한다. 원래 제외 객체는 단계 출력과 `s6_lineage_reviews`에 보존하며, 사유를 대표안의 위험 항목에 넣어 독립 검토가 읽는다. 원래 유료 호출 응답은 변경하지 않는다.

알 수 없는 ID, 다른 대표안 ID, 중복 소속·판정, 누락된 대표안, 잘못된 필수 필드 등은 계속 검증에 실패한다. 생성기는 후보를 승인할 수 없으며 모든 후보는 기존 독립 검토를 거친다. 판정 형식이 여전히 잘못되면 화면에 고정된 설명을 표시하고 내부 ID나 모델 응답은 노출하지 않는다.

생성 요청의 프롬프트·변수는 유지한다. 저장된 실제 최초 응답과 두 수리 응답을 오프라인에서 재생하여 대표 판정 한 개와 원안 의견 한 개가 보존되는 것을 확인했다. 원안 의견 이동은 트랙·과학효과에 새 보상을 부여하는 평가 이벤트가 아니다.

프런트의 ‘기법 선택과 학습 상태’ 카드는 모든 탭에서 제거한다. 실제 실행 단계 표시, 사용자 검토, 최종 피드백 기능은 유지한다.

검증: 관련 백엔드 회귀 119개 및 실제 gateway/ledger 경로의 재개·비용 불변 테스트 2개 통과. 프런트 빌드 및 관련 Playwright 테스트 2개 통과. 운영 분석 재개, 운영 데이터 수동 수정, 유료 LLM 호출은 수행하지 않았다. 정상적인 후속 독립 검토에는 별도 모델 호출이 필요할 수 있으며 생성 호출 재사용과 구분한다.
