# 사용자 표시 참조와 Sample Case 진입 화면

2026-09-11 변경.

- 해결안 참조는 저장된 개념 순서에 따라 `해결안1 (핵심 내용)`으로 표시한다. 평가 순위와 표시 번호를 구분하며 카드, 피드백, 역질의와 보고서에서 동일한 번호를 사용한다.
- 소문자·기존 괄호 표기·한국어 조사·저장된 비표준 ID도 매칭한다. 원본 항목을 찾을 수 없는 내부 ID는 코드 대신 `해결안 (내용 확인 필요)` 등으로 표시한다.
- 역질의 질문/추천 답변, 알림, 프로젝트 목록, 해결안 설명/검증 계획/참고자료, 보고서 본문과 도표에 적용한다. SVG는 줄바꿈 전에 치환한다.
- 표시용 복사본만 변환한다. 원본 상태, 선택/재개/피드백용 식별자, 특허번호/DOI/URL은 유지한다. 기존 보고서도 조회와 다운로드 시 현재 표시 로직을 적용한다.
- Sample Case 목록에서 프로젝트를 열거나 탭 없는 프로젝트 주소로 접근하면 `문제 정의`를 먼저 표시한다. 명시적인 보고서 링크와 브라우저 탐색 기록은 유지한다.

검증: 백엔드 전체 329개 통과. 최종 표시 처리 변경 후 관련 32개 재검증 통과. 운영 상태의 읽기 전용 스냅샷 47건에서 화면 데이터·Markdown·HTML·SVG를 검사했으며, 수정 전 코드가 검출된 42건이 수정 후 0건으로 감소했다. 스냅샷 원본은 변경하지 않았다. 실데이터가 담긴 검증 파일은 `.deployment/`에만 보관한다.

핵심 회귀 검증은 `pilot/tests/test_display_labels.py`에 있다. 배포 파일은 `deploy/deploy_display_labels.py`의 명시적 목록으로 준비한다.
