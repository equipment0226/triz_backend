### 비용 기록의 한계

위 금액은 실행 시 pin한 기존 `COST_IN/OUT_PER_M_*` 설정으로 토큰을 환산한 값이다. 공급자 청구서를 조회해 확인한 금액은 아니다. 2026-09-16 후속 조회에서 DeepSeek `/models`는 `deepseek-flash`, `deepseek-v4-pro`를 반환했으며 [공식 가격표](https://api-docs.deepseek.com/quick_start/pricing/)도 모델·시간대별 요금을 표시한다. 두 시험은 기존 `deepseek-chat` 별칭으로 성공했으나 당시 응답의 실제 model ID는 저장하지 않아 현재 모델과 청구 단가의 대응은 확정할 수 없다. 이후 응답에는 requested/provider model을 모두 기록하도록 보강했다. 따라서 공급자 실제 청구액의 $0.60 이하 여부는 별도 확인이 필요하다. 이 점을 숨기고 환산액을 실청구액으로 표현하지 않는다.
