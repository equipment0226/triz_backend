# 과학효과 400개 배포 완료

## 분석 방식과 근거

- 기존 방식을 유지했다. MySQL에 저장된 특허 초록을 Astra 대화에서 직접 읽고 원리를 판단했다. 외부 LLM API 호출은 0회이며, 기록·연결·발행 스크립트가 분석을 대신하지 않는다.
- 페이지 31·32의 특허 초록 400건을 추가 검토했다. 누적 직접 검토 2,912건, 가져온 기록 3,360건, 초록 없는 기록 448건, 가져온 미검토 기록 0건이다. 특허 전문 전체를 읽었다는 의미는 아니다.
- 누적 판단은 LINK 1,270건, DEFER 978건, DESIGN_ONLY 657건, REJECT_CLAIM 7건이다. LINK는 연결한 특허 수이며 효과 개수와 다르다.
- 신규 40개 모두 저장 특허와 원리 문헌이 연결되어 있다. 새 참고문헌 41개를 추가했으며 기존 360개 ID를 보존했다. 총 400개 중 출처가 연결된 효과 381개, 기존 편집 지식만 있는 효과 19개다.
- 초록에서 명시한 내용과 일반 원리 문헌을 통해 추론한 적용 관계를 검토 메모에서 구별했다. 광열 경화, 카보머 현탁, 마이야르 갈변, 이중층 반발 등은 저장 초록이 세부 기전을 직접 측정했다는 뜻이 아니다. 출처의 성능 수치나 임상 결과를 특허에 전이하지 않았다.
- 화학·재료·유체·측정·생명과학·통신을 함께 검토했다. IT 특허도 같은 순차 검토 대상이다.
