## 모델과 요율

운영 계정의 모델 목록에서 `deepseek-flash`를 확인하고 T1/T2/T3에 명시했다. 기존 chat 경로의 비추론 모드를 유지하기 위해 `thinking.type=disabled`를 지정하고 실행 bundle에도 고정한다. [공식 모델·요금표](https://api-docs.deepseek.com/quick_start/pricing/)와 [모드 설정](https://api-docs.deepseek.com/guides/thinking_mode/)을 확인했다.

원장에는 입력 $0.30/M, 출력 $1.20/M의 피크·입력 캐시 미적중 요율을 사용한다. 비피크·캐시 할인은 차감하지 않으므로 설정 환산액은 보수적인 추정치이며 공급자 청구서와 구분한다. 기존 두 DLC 시험의 실제 청구액은 소급 확인되지 않았다. 이번 배포 검증에서는 유료 모델 호출을 하지 않았다.
