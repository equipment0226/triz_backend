# 과학효과 중복 재검토 및 600개 확장

2026-09-23 KST. 기존 500개를 재검토하고 저장 특허의 다음 1,000개 초록을 직접 읽어 신규 효과 100개를 작성했다. 운영 배포 및 검증을 완료했다.

## 중복과 근거 검토

- 기존 500개의 이름·원리·조건을 직접 비교했다. 완전히 같은 내용으로 판단하여 병합한 항목은 없지만 상하위 원리·공유 기전·기능이 겹치는 58개 관계 묶음을 기록했다. 독립적인 자연법칙 500개 또는 600개라는 뜻은 아니다.
- 신규 후보 122개 가운데 중복·근거 범위 문제 등으로 22개를 제외했다. 채택한 100개 모두 기존 또는 신규의 유사 원리와 구분 조건을 기록했다. 수류 결속과 니들 펀칭은 섬유 얽힘으로, 송신·수신 다이버시티는 공간 다이버시티로 묶었다.
- 기존 `biofilm-treatment`의 제목을 “생물막 분해”에서 “생물막에 의한 오염물 분해”로 명확히 했다. ID와 원리 내용은 보존했다. 기존 500개 ID 모두 유지했다.
- 광학 외관 변경을 센싱으로 연결한 `AR-085378-A1`, 센서 종류가 불명확한데 압저항으로 연결한 `AR-085883-A1`을 별도 재검토 기록에서 DEFER로 정정하고 두 출처 연결을 제거했다.
- 최종 600개에 중복 키·제목·동일 원리 문자열은 없다. 문자열 검사는 의미 중복 검토를 대신하지 않으며 상위·하위 응용 관계는 각 항목의 조건과 검토 기록에 남긴다.

## 분석 방식과 범위

- MySQL에 저장된 특허 초록을 Astra 대화에서 직접 읽고 판단하는 기존 방식을 유지했다. 외부 LLM API 호출은 0회다. 저장 스크립트는 직접 작성된 판단을 기록·연결·발행한다.
- 페이지 37–41의 초록 1,000건 추가 검토. 누적 조회 5,160건, 직접 읽은 초록 4,711건, 초록 없음 449건, 가져온 미검토 0건이다. 특허 청구항·명세서 전문 전체를 읽은 것은 아니다.
- 신규 100개 모두 원리 참고문헌과 저장 특허를 연결했다. 신규 효과에 직접 연결한 고유 특허는 93건이며 한 특허에 여러 원리가 있을 수 있다. 문헌으로 보완한 일반 원리를 특허가 세부적으로 실증했다는 의미로 취급하지 않는다.
- 누적 LINK 2,413건, DEFER 1,401건, DESIGN_ONLY 886건, REJECT_CLAIM 11건이다. LINK는 연결 특허 수이며 효과 수와 다르다.
- 최종 600개 중 출처 연결 588개, 기존 편집 지식만 있는 항목 12개다. 기존 효과에도 추가 특허를 연결하여 출처 보유 수가 신규 100개보다 3개 더 증가했다.
