# 피드백 증가 회귀 및 EBEAM 제목 수정

2026-09-29, 기존 배포 `0ae7ef0` 이후 증가한 실제 분석·피드백을 읽기 전용으로 점검했다. 확인된 수치 판정 오염과 최종 후보 버전 연결 문제를 수정하며 기존 원장, 보고서, 유료 응답은 소급 변경하지 않는다.

## 수정 내용

- S7 수치 보조 검사는 동일 파라미터·단위·적용 영역에 직접 연결된 명시적 실측값만 비교한다. 내부 ID, 다른 물리량, 목표·미측정·추정, 불명확한 경계는 실패의 근거로 사용하지 않는다. 판단 유보는 기술적 통과를 의미하지 않는다.
- 확정 수치 위반은 원래 AI 판정, 검사 문자열, 제약을 함께 기록한다. 필드 경계를 줄바꿈으로 보존하고, 같은 제약의 UNKNOWN/FAIL 중복을 제거한다.
- 신뢰 가능한 검사 계약이 없는 과거 수치 override는 공통 평가의 학습 projection에서 미관측으로 격리한다. 원문과 원점수는 그대로 남고, 격리 사유 및 원값을 반환한다. 독립 AI 검토와 실제 사용자 선호는 별도로 보존한다.
- S9 근거·적용조건 보강으로 후보 버전이 달라졌을 때 S10의 실제 최종 점수를 사용한다. 변경 전 후보의 AI 품질을 승계하지 않는다. 동일 설계의 keep은 재검토 이후에도 선호로 유지하되 REJECT를 무효화하지 않는다.
- 점수 정정은 원래 관측한 후보에 귀속하고, 과거 cutoff에 미래 점수를 반영하지 않는다. 동의 철회는 관련 정정 체인에 즉시 적용한다.
- 효과 학습은 최신 후보 버전을 먼저 선택한다. 원리가 변경되거나 채택 효과가 제거된 경우 옛 효과 표본을 남기지 않는다. 같은 원리를 공유하는 다른 후보의 점수를 해당 효과의 사용 근거로 취급하지 않는다.
- Q·효과 모델의 후보 projection 및 평가 무결성 계약을 명시한다. 이전 계약 모델은 명시적 fallback을 사용하며 실행 중 저장 bundle은 덮어쓰지 않는다.
- 무효화된 과거 시험 결과를 성숙도 근거로 남기지 않는다. 실제 사용할 품질·효용 관측이 모두 없으면 비용만 있는 Q 학습 표본을 생성하지 않는다.
- 자동 제목은 사용자 확정 대상의 EBEAM/E-beam/전자빔을 보존한다. EUV 공정 맥락을 E-beam 검사 수단으로 오인한 초기 제목은 리스트·상세·보고서 표시에서 보정한다. 사용자 지정 제목은 유지하며 S1/S2에서 자동 제목 갱신 이력을 기록한다.

## 실제 데이터 확인

08:39 KST 기준 동일 프로젝트는 38개 분석, 배포 이후 신규 분석 7개, 공통 평가 619건, 최종 피드백 관측 81건이었다. Q v5 표본은 23전이/3문제에서 41전이/5문제로 늘었고, 효과 표본은 3개에서 7개로 늘었다. 등록 모델은 0개이며 준비 기준을 완화하거나 강제 활성화하지 않았다.

저장된 S7 입력 22건을 기존 배포 코드와 수정 코드로 오프라인 재생했다. 큐비트의 ID 숫자 오인 4건 외에도 심해 케이블에서 수심·굽힘 반경·외경의 숫자와 단위가 섞이는 4건이 재현됐다. 수정 코드에서는 해당 8개 수치 위반이 발생하지 않았다. 별도 회귀에서는 명시적인 실제 측정 위반이 계속 검출되는지 확인한다.

해당 원인에서 생성된 공통 평가 7건은 학습 projection에서 격리됐다. BCI 최종 5점 관측 1건은 새 후보의 사용자 효용에 포함되며, 같은 후보의 옛 품질 값은 제외된다. 이는 저장 데이터로 다시 계산한 결과이며 운영 원장 수정이나 모델 성능 개선의 증거가 아니다.

EBEAM 사례의 원문은 EUV를 제조 공정 맥락으로, E-beam을 검사 수단으로 언급했다. 후속 사용자가 E-beam 검사 대상을 확정했지만 초기 자동 제목이 갱신되지 않았다. 실제 저장 상태의 핵심 분석 대상은 E-beam으로 유지돼 있었다. 새 표시 함수는 같은 저장 입력에서 `EBEAM 웨이퍼 결함 검출의 조사 에너지 상충 해결`을 반환하며 운영 checkpoint를 쓰지 않는다.
