# 변경 기록

## 2026-09-30 · S5 중단 후 재개

시간 한도나 워커 종료 후 초기 탐색을 재개하면, 새 snapshot과 이전 선택 티켓이 충돌해 `stale_input_snapshot`으로 반복 실패하던 문제를 수정했습니다. 실제 입력이 같은지 원래 결정·액션·아티팩트 기록으로 확인하고 기존 선택을 이어갑니다. 이미 완료된 트랙은 다시 실행하지 않고 미완료 통합만 처리합니다.

원본 입력·산출물·비용 기록을 보존하며, 사용량 미확인 호출은 기존 예약과 승인된 1회 재시도에 계속 연결합니다. 실제 실패 3건의 기록을 격리된 로컬 DB에서 검증했고, 램젯 통합 요청은 운영에 저장된 요청 해시와 일치했습니다. 이 검증에서 운영 데이터 변경이나 유료 모델 호출은 없었습니다. [재개 계약](OPERATIONS.md#중단재개와-사용량-미확인)을 함께 확인하세요.

## 2026-09-30 · 첨부 처리 보안 보완

실패한 새 첨부 요청이 미연결 파일을 남기는 문제를 수정했습니다. 부분 저장이나 요청 취소 뒤에도 프로젝트에 연결된 원본은 보존합니다. PDF·XLSX·OCR 추출에는 별도 worker와 시간·메모리·동시 실행 제한을 적용했습니다. 기존 프로젝트, 첨부, 피드백과 학습 결과를 정리하거나 변환하지 않았고, 베타 공개 기능도 유지했습니다. [점검 범위와 처리 한도](SECURITY.md)를 참고하세요.

## 2026-09-30 · 보고서 적용 도식과 문서 정비

분리원리 그림을 아이디어별 실제 적용 내용으로 바꿨습니다. 기법별 아이디어 섹션에만 표시하고 마지막 해결안 섹션에서는 반복하지 않습니다. 타산업 기능 이식 뒤의 해결 범위·탐색 보완 종합서술도 제거했습니다. 76표준해의 일반 참고 그림과 하위 대안·분기 도식은 보고서에서 제거했습니다. 저장된 적용 전후 모델과 S3 물질-장 모델, 기존 해결안 도식은 유지하고 Introduction 도식은 보존했습니다.

빈 표와 반복 안내를 줄이고, 이후 생성되는 S5/S6/S9 문장을 구체적이고 간결하게 쓰도록 프롬프트를 정리했습니다. 과거 분석을 다시 추론하거나 기술 판정·미확인 조건을 바꾸지는 않았습니다.

문서는 [기획](PRODUCT.md), [전체 설계](ARCHITECTURE.md), [Stage](STAGES.md), [모듈](MODULES.md), [학습](LEARNING.md), [모드](MODES.md), [사용](USAGE.md), [운영](OPERATIONS.md)으로 통합했습니다. Stage 입출력·검증, 효과·특허 위치, AI/사용자 평가 환류, 보상식·가중치, 모드별 흐름을 현재 코드로 대조했습니다. README와 목차도 이 구조로 바꿨습니다.

중복 설계서·작업 지시서·과거 장애/배포 메모는 백업 후 제거했습니다. `docs/` 원본 83개, 현재 Git 체크아웃 79개, 이전 `release/triz_backend/docs` 복사본 29개입니다. 같은 문서의 복사본도 별도로 센 수입니다. 정본 출처 검토와 런타임 프롬프트는 보존했습니다. 과거 문서는 [정리 직전 커밋의 docs](https://github.com/equipment0226/triz_backend/tree/eae3f0aa1a8737365cc7e4cc589c3494775c9026/docs)에서 확인할 수 있습니다.
