# ARIZ Part 6 보고서 추가 의견

2026-09-26 결정: 보고서에 포함된 Solution이 **3개 이하**일 때 6.1~6.3을 검토하여 문제 변경을 제안한다. 현재 해결책 도출 흐름은 유지한다.

## 동작

- 기준은 S5 중간 아이디어 수가 아니라 최종 보고서의 서로 다른 해결책 ID 수다. 조건부 해결책도 보고서에 표시되므로 포함한다.
- 1~3개이면 기존 `s8_rank` 호출에 문제 정의·모순·제약·상위 시스템 정보를 전달하고, 각 항목의 관찰과 변경 제안을 받는다. 4개 이상이면 이 부가 맥락을 전달하지 않고 의견도 저장하지 않는다.
- 6.1은 복합 문제 분해, 6.2는 ARIZ 1.4에서 다른 모순 선택, 6.3은 상위 시스템 관점에서 ARIZ 1.1 미니문제 재정의다. 요구 수준을 낮추는 별도 6.3이나 6.4를 새로 생성하지 않는다. 과거 저장된 ARIZ 단계 기록은 수정하지 않는다.
- 결과는 `evaluation.problem_reformulation_review`에 저장하고 전체·간이·HTML 보고서의 한계 항목에 추가 코멘트로 표시한다. ARIZ 해법 도출 트랙을 실행하지 않은 경우에도 사용할 수 있다.
- 이 의견은 채택 전 제안이다. 원래 문제·필수 제약·해결책·순위·로드맵을 수정하거나 S1/ARIZ Part 1로 되돌리는 동작을 추가하지 않는다.

## 호출 및 호환성

별도 모델 호출, 수리 호출, 재귀 실행을 추가하지 않는다. 기존 순위 호출의 입력·출력 토큰만 늘어난다. 해결책이 0개여서 순위 호출을 건너뛰거나, 항목별 응답이 누락/잘못된 형식이면 기존 분석 기록에 근거한 확인 질문을 제공한다. 이 경우에는 모델의 개별 검토 응답이 없음을 보고서에 표시한다.

이전 AX 실행에 고정된 프롬프트는 교체하지 않는다. 새 검토 필드가 없는 응답은 위의 기록 기반 질문으로 처리한다. 이미 완료된 과거 보고서에 검토를 수행한 것처럼 소급해서 의견을 넣지 않는다.

AX 보고서는 현재 순위 산정 전 고정된 후보 목록을 표시하므로 그 목록의 개수를 사용한다. 일반 실행은 순위 산정 후 실제 남은 목록을 사용한다. AX의 기존 후보 표시·선정 정책은 이 변경에서 수정하지 않는다. 평가 데이터에 저장한 의견은 AX 스냅숏에도 포함된다.

평가 재실행 시 이전 의견을 지우며, 렌더링 시 의견에 저장된 해결책 ID 집합이 표시 대상과 다르면 숨긴다. 라이브 상태 변경이 완료된 AX 보고서의 의견을 덮어쓰지 않는다.

## 오프라인 회귀 검증

`pilot/tests/test_ariz_reformulation.py`는 0/1/3/4개 경계, 조건부 해결책 포함, 모델 호출 횟수 유지, 응답 누락·형식 오류, 문제·제약·해결책 불변, 평가 재실행과 과거 의견 무효화, 전체·간이·HTML 출력, AX 스냅숏 고정 및 후보 수 상한 차이를 검증한다. 실제 모델의 제안 품질 평가는 포함하지 않는다.
